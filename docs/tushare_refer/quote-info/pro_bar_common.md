# 通用行情接口

接口名称：`pro_bar`

接口说明：本接口是 Tushare Pro 的集成开发接口，整合了股票（未复权、前复权、后复权）、指数、ETF基金、期货、期权、可转债等资产的行情数据，并支持分钟级数据。部分指标为现用现算，部分指标第一条可能为 NaN，请注意日期参数跨度。

更新时间：股票和指数通常在交易日 15:00 ~ 17:00 之间更新，具体请参考各资产类别文档明细。

注意：由于本接口在 SDK 层做了逻辑处理，目前暂时无法通过 HTTP 方式直接调取。如需 HTTP 调用，建议访问 Tushare Github 查看源代码实现类似功能，或使用其他专用接口。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 证券代码，不支持多值输入，多值输入获取结果会有重复记录 |
| start_date | str | N | 开始日期。日线格式：YYYYMMDD；分钟数据格式：2019-09-01 09:00:00 |
| end_date | str | N | 结束日期。日线格式：YYYYMMDD |
| asset | str | N | 资产类别： <br> E - 股票 (默认) <br> I - 沪深指数 <br> FT - 期货 <br> FD - 基金 <br> O - 期权 <br> CB - 可转债 (v1.2.39+) |
| adj | str | N | 复权类型（只针对股票）： <br>  None - 未复权 (默认) <br> qfq - 前复权 <br> hfq - 后复权 <br> 注：目前只支持日线复权。复权机制是根据设定的 `end_date` 参数动态复权，采用“分红再投”模式。 |
| freq | str | N | 数据频度： <br> D - 日线 (默认) <br> W - 周线 <br> M - 月线 <br> 1min/5min/15min/30min/60min - 分钟K线 <br> 注：分钟数据需 600 积分试用（请求2次），正式权限参考权限列表。 |
| ma | list | N | 均线，支持任意合理 int 数值。注：均线是动态计算，开始和结束日期跨度必须超过均线周期才能获得有效值（如 ma_5 需跨度 > 5日）。目前只支持单只股票提取均线。例如：`ma=[5, 10, 20]` 将生成 `ma_5`, `ma_10`, `ma_20` (均价) 和 `ma_v_5`, `ma_v_10`, `ma_v_20` (均量)。 |
| factors | list | N | 股票因子（仅当 asset='E' 时有效）。支持： <br> tor - 换手率 <br> vr - 量比 |
| adjfactor | str/N | N | 复权因子。在复权数据时，如果此参数为 True，返回的数据中则带复权因子列，默认为 False。该功能从 1.2.33 版本开始生效。 |

## 输出指标

具体输出的数据指标取决于资产类别 (`asset`) 和频率 (`freq`)，常见字段包括：

* **基础行情**：`ts_code`, `trade_date`, `open`, `high`, `low`, `close`, `pre_close`, `change`, `pct_chg`, `vol` (成交量), `amount` (成交额)
* **均线**：`ma_x` (x日均价), `ma_v_x` (x日均量)
* **因子**：`tor` (换手率), `vr` (量比)
* **复权因子**：`adj_factor` (当 `adjfactor=True` 时)

详细字段定义可参考各类资产的具体文档：

* [股票 Daily](https://tushare.pro/document/2?doc_id=27)
* [基金 Daily](https://tushare.pro/document/2?doc_id=127)
* [期货 Daily](https://tushare.pro/document/2?doc_id=138)
* [期权 Daily](https://tushare.pro/document/2?doc_id=159)
* [指数 Daily](https://tushare.pro/document/2?doc_id=95)

## 接口用例

### 获取股票前复权日线行情

```python
import tushare as ts

pro = ts.pro_api()

# 取 000001.SZ 的前复权行情
df = pro.pro_bar(ts_code='000001.SZ', adj='qfq', start_date='20180101', end_date='20181011')
```

### 获取带均线和因子的股票行情

```python
import tushare as ts

pro = ts.pro_api()

# 获取 000001.SZ 的日线，包含 5日、10日均线，以及换手率和量比
df = pro.pro_bar(
    ts_code='000001.SZ',
    start_date='20230101',
    end_date='20231231',
    ma=[5, 10],
    factors=['tor', 'vr']
)
```
