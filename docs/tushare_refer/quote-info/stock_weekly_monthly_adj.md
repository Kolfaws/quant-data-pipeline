# 股票周/月线行情(复权--每日更新)

接口名称：`stk_week_month_adj`

接口说明：提供股票的周线和月线行情数据，包含未复权价格及前复权、后复权价格。数据每日更新，通常在17点和22点进行刷新。相比 `stk_weekly_monthly`，本接口直接提供了复权后的OHLC数据，无需通过通用接口计算。

限量：单次最大 6000 条，可使用交易日期循环提取，总量不限制。

积分：用户需要至少 2000 积分才可以调取，具体请参阅积分获取办法。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | TS代码 |
| trade_date | str | N | 交易日期，格式：YYYYMMDD。填写每周或每月最后一个交易日的日期 |
| start_date | str | N | 开始交易日期 |
| end_date | str | N | 结束交易日期 |
| freq | str | Y | 频率：week 表示周线，month 表示月线 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 股票代码 |
| trade_date | str | Y | 交易日期（每周五或者月末日期） |
| end_date | str | Y | 计算截至日期 |
| freq | str | Y | 频率，week 表示周，month 表示月 |
| open | float | Y | (周/月)开盘价（未复权） |
| high | float | Y | (周/月)最高价（未复权） |
| low | float | Y | (周/月)最低价（未复权） |
| close | float | Y | (周/月)收盘价（未复权） |
| pre_close | float | Y | 上一(周/月)收盘价【除权价，前复权基准】 |
| open_qfq | float | Y | 前复权(周/月)开盘价 |
| high_qfq | float | Y | 前复权(周/月)最高价 |
| low_qfq | float | Y | 前复权(周/月)最低价 |
| close_qfq | float | Y | 前复权(周/月)收盘价 |
| open_hfq | float | Y | 后复权(周/月)开盘价 |
| high_hfq | float | Y | 后复权(周/月)最高价 |
| low_hfq | float | Y | 后复权(周/月)最低价 |
| close_hfq | float | Y | 后复权(周/月)收盘价 |
| vol | float | Y | (周/月)成交量 |
| amount | float | Y | (周/月)成交额 |
| change | float | Y | (周/月)涨跌额 |
| pct_chg | float | Y | (周/月)涨跌幅 【基于除权后的昨收计算的涨跌幅：（今收-除权昨收）/除权昨收 】 |

## 接口用例

### 获取某只股票的周线复权行情

```python
import tushare as ts

pro = ts.pro_api()

# 获取 000001.SZ 的周线数据（含复权字段）
df = pro.stk_week_month_adj(ts_code='000001.SZ', freq='week')
```

### 获取指定日期的全市场月线复权行情

```python
import tushare as ts

pro = ts.pro_api()

# 获取 2025年10月的所有股票月线数据
df = pro.stk_week_month_adj(trade_date='20251031', freq='month')
```

### 获取时间区间内的周线数据

```python
import tushare as ts

pro = ts.pro_api()

# 获取 000001.SZ 从 2024年初到 2025年10月的周线数据
df = pro.stk_week_month_adj(
    ts_code='000001.SZ',
    start_date='20240101',
    end_date='20251024',
    freq='week'
)
```
