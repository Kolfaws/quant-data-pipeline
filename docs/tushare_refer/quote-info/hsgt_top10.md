# 沪深股通十大成交股

接口名称：`hsgt_top10`

接口说明：获取沪股通、深股通每日前十大成交股的详细数据，包括成交金额、净买入额、买卖方向等。数据通常在每个交易日 18:00 ~ 20:00 之间完成更新。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | TS股票代码（与 trade_date 二选一） |
| trade_date | str | N | 交易日期（格式：YYYYMMDD，与 ts_code 二选一） |
| start_date | str | N | 开始日期（格式：YYYYMMDD） |
| end_date | str | N | 结束日期（格式：YYYYMMDD） |
| market_type | str | N | 市场类型：<br>1 - 沪市（沪股通）<br>3 - 深市（深股通） |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| trade_date | str | Y | 交易日期 |
| ts_code | str | Y | 股票代码 |
| name | str | Y | 股票名称 |
| close | float | Y | 收盘价 |
| change | float | Y | 涨跌额 |
| rank | int | Y | 资金排名（1-10） |
| market_type | str | Y | 市场类型（1：沪市，3：深市） |
| amount | float | Y | 成交金额（元） |
| net_amount | float | Y | 净成交金额（元），正数表示净买入，负数表示净卖出 |
| buy | float | Y | 买入金额（元） |
| sell | float | Y | 卖出金额（元） |

## 接口用例

### 获取指定日期的沪股通十大成交股

```python
import tushare as ts

pro = ts.pro_api()

# 获取 2018年7月25日 沪股通（市场类型1）的前十大成交股
df = pro.hsgt_top10(trade_date='20180725', market_type='1')
```

### 获取某只股票在深股通的歷史成交记录

```python
import tushare as ts

pro = ts.pro_api()

# 查询 600519.SH (贵州茅台) 在 2018年7月1日至7月25日期间出现在深股通或沪股通十大成交中的记录
# 注意：贵州茅台是沪市股票，通常出现在 market_type='1' 中，此处仅为演示 ts_code 用法
df = pro.query('hsgt_top10', ts_code='600519.SH', start_date='20180701', end_date='20180725')
```

### 获取指定时间段内的深股通十大成交股

```python
import tushare as ts

pro = ts.pro_api()

# 获取 2023年10月全月的深股通（市场类型3）十大成交数据
df = pro.hsgt_top10(
    start_date='20231001',
    end_date='20231031',
    market_type='3'
)
```
