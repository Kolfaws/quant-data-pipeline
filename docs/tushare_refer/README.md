## 2. 单个文件的结构

每个接口文件统一包含：

1. `# 中文名称`
2. `接口：<接口名>`，以及官方描述
3. `描述` / `限量` / `积分` / `权限` 等元信息（保留官方原文）
4. `## 输入参数`：名称、类型、必选、描述
5. `## 输出参数`：名称、类型、默认显示、描述
6. `## 接口示例`：Python 调用示例
7. `## 数据样例`：官方返回样例（`text` 代码块）

不同接口的官方页面结构略有差异；个别文件会多出“市场说明”“指数列表”“板块代码”“汇率字典”等补充表，均按原顺序保留。

## 3. 积分与权限（重要）

- 当前环境按 **5000 积分** token 设计；积分与频次对应表见
  [`basic-info/points_refer.md`](basic-info/points_refer.md)。
- 各接口文件里的“积分 / 权限 / 限量”是**官方原文**，部分接口要求 6000、8000、10000 积分或单独开通权限（例如分钟数据、港股/美股财报、部分 ETF 接口）。
- 5000 积分可覆盖大部分日频行情、基础信息、财务、宏观和参考数据；ETF 列表/日线、部分特色数据、分钟数据仍需更高积分或单独权限。
- 调用前先看目标文件中的“积分/权限”段，不要仅按目录判断可用性。

## 4. 安全约定

- 示例代码中的 token 是占位符（如 `<--your-token-->`、`'your token'`），不要替换为真实 token 后提交。
- 真实 token 只放在本机 `.env`，由 `data_pipeline.config` 读取，不写入文档。
