# 财务审计意见

接口名称：`fina_audit`

接口说明：获取上市公司定期财务报告（年报、半年报等）的审计意见数据。包含审计结果类型、审计费用、会计师事务所及签字会计师等信息。审计意见是评估公司财务数据可信度和潜在风险的重要指标。

权限：用户需要至少 2000 积分才可以调取，具体请参阅积分获取办法。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | TS股票代码 |
| ann_date | str | N | 公告日期（YYYYMMDD格式） |
| start_date | str | N | 公告开始日期（YYYYMMDD格式） |
| end_date | str | N | 公告结束日期（YYYYMMDD格式） |
| period | str | N | 报告期（每个季度最后一天的日期，如 20171231 表示年报，20170630 表示半年报） |

## 输出参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| ts_code | str | TS股票代码 |
| ann_date | str | 公告日期 |
| end_date | str | 报告期 |
| audit_result | str | 审计结果（见下方说明） |
| audit_fees | float | 审计总费用（元） |
| audit_agency | str | 会计师事务所名称 |
| audit_sign | str | 签字会计师姓名 |

## 常见审计结果类型说明

* **标准无保留意见**：财务报表在所有重大方面按照会计准则编制，公允反映了公司财务状况。这是最理想的结果。
* **带强调事项段的无保留意见**：虽然报表公允，但存在某些重大事项（如持续经营能力不确定性、重大诉讼等）需要提醒投资者注意。
* **保留意见**：财务报表整体公允，但存在个别重大错报或审计范围受限，影响局部判断。
* **否定意见**：财务报表存在重大且广泛的错报，不能公允反映公司财务状况。
* **无法表示意见**：审计范围受到严重限制，注册会计师无法获取充分、适当的审计证据，因而无法对财务报表发表意见。这通常意味着极高的风险。

## 接口用例

### 获取单只股票的历史审计意见

```python
import tushare as ts

pro = ts.pro_api()

# 获取 600000.SH (浦发银行) 从 2010年到 2018年的审计意见数据
df = pro.fina_audit(
    ts_code='600000.SH',
    start_date='20100101',
    end_date='20180808'
)
```

### 获取指定报告期的审计信息

```python
import tushare as ts

pro = ts.pro_api()

# 获取 000001.SZ 2023年年报的审计信息
df = pro.fina_audit(
    ts_code='000001.SZ',
    period='20231231'
)
```
