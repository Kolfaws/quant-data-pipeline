# 美股ETF日行情表

接口：`us_etf_daily`，可以通过数据工具调试和查看数据

描述：获取美股ETF基金每日收盘后成交行情数据，包含部分OTC的盘后行情数据。

限量：单次最大6000行数据，可根据日期参数循环提取，开通正式权限后也可支持分页提取全部历史

权限：本接口数据需单独开通权限，请参考权限列表，前往权限中心申请（需勾选“美股历史日线”）。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | 基金代码 |
| trade_date | str | N | 交易日期（YYYYMMDD） |
| start_date | str | N | 开始日期（YYYYMMDD） |
| end_date | str | N | 结束日期（YYYYMMDD） |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 股票代码 |
| trade_date | str | Y | 交易日期 |
| close | float | Y | 收盘价 |
| open | float | Y | 开盘价 |
| high | float | Y | 最高价 |
| low | float | Y | 最低价 |
| pre_close | float | Y | 昨收价 |
| change | float | Y | 涨跌额 |
| pct_change | float | Y | 涨跌幅 |
| vol | None | Y | 成交量 |
| amount | float | Y | 成交额 |
| vwap | float | Y | 平均价 |
| turnover_ratio | float | N | 换手率 |
| total_mv | float | N | 总市值 |

## 接口示例

```python
pro = ts.pro_api()

#获取单一股票行情
df = pro.us_etf_daily(ts_code='AAAU', start_date='20260101', end_date='20260904')

#获取某一日所有股票
df = pro.us_etf_daily(trade_date='20261022')
```
