# 美股恐慌指数行情

接口：`vix_index`，可以通过数据工具调试和查看数据

描述：VIX恐慌指数由美国CBOE芝加哥期权交易所编制，底层标的为标普500（S&P 500）期权，主要用于反映美股大盘对未来波动的预期，因此常被视为美股市场恐慌情绪的重要指标。它并不是股票，也不是股票指数，而是一个波动率指数。其数值通过标普500的看涨期权和看跌期权价格计算得出，用来衡量市场对未来30天美股大盘波动程度的预期。当美股大幅下跌时，投资者往往会大量买入看跌期权进行保护，推动VIX快速上涨，所以它也被称为“恐慌指数”。简单参考区间：低于20：市场比较平静，恐慌情绪较低。20—30：市场担忧上升，波动预期增强。高于30：市场出现明显恐慌。高于40：通常意味着重大危机级别，市场处于极度恐慌状态。

限量：单次最大300条，可根据代码或日期循环提取

积分：需要5000积分可以调取，具体请参阅积分获取办法

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| trade_date | str | N | 交易日期(格式：YYYYMMDD，下同) |
| start_date | str | N | 开始日期 |
| end_date | str | N | 结束日期 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| trade_date | str | Y | 交易日期 |
| high | str | Y | 最高价 |
| low | str | Y | 最低价 |
| open | str | Y | 开盘价 |
| close | str | Y | 收盘价 |
| pct_change | str | Y | 涨跌幅 |

## 接口示例

```python
# 导入sdk包
import tushare as ts

# 配置凭据，如果已全局配置了，可以忽略。
ts.set_token('<--your-token-->')

# 获取接口实例
pro = ts.pro_api()

# 拉取接口(vix_index)数据
# 获取2026年9月1日以来的数据
df = pro.vix_index(start_date="20260901")
print(df)
```
