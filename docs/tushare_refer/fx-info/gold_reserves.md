# 黄金储备

接口：`gold_reserves`，可以通过数据工具调试和查看数据

描述：获取国家外汇管理局公布的官方储备资产黄金储备月度数据，含美元、SDR、持有量三重口径。数据开始于2018年01月12日，为月度更新数据。

限量：单次最大3000条，可根据代码或日期循环提取

积分：需要5000积分可以调取，积分权限可在权限中心获取

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| month | str | N | 月份（格式：YYYYMM） |
| start_date | str | N | 开始月份（格式：YYYYMM） |
| end_date | str | N | 结束月份（格式：YYYYMM） |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| month | str | Y | 统计月份，YYYYMM，如202601 |
| ann_date | str | Y | 公告/发布日期，YYYYMMDD，取页面PubDate |
| gold_usd | float | Y | 黄金储备市值，单位：亿美元 |
| gold_sdr | float | Y | 黄金储备市值，单位：亿SDR |
| usd_sdr | float | Y | 当月USD/SDR折算汇率，来源IMF |
| gold_oz | float | Y | 黄金持有量，单位：万盎司 |

## 接口示例

```python
# 导入sdk包
import tushare as ts

# 获取接口实例
pro = ts.pro_api()

# 获取2026年1月到2026年10月的黄金储备数据
df = pro.gold_reserves(start_date='202601', end_date='202610')
print(df)
```
