# 外汇储备

接口：`fx_reserves`，可以通过数据工具调试和查看数据

描述：获取自 1999 年 12 月至今的全部外汇储备记录。数据包含美元（USD）与国际货币基金组织特别提款权（SDR）两种口径；其中 SDR 口径自 2016 年 4 月起官方公布，为月度更新数据。

限量：单次最大3000条，可根据代码或日期循环提取

积分：需要5000积分可以调取，积分权限可在权限中心获取

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| month | str | N | 月份（格式：YYYYMM） |
| start_date | str | N | 开始月份（格式：YYYYMM） |
| end_date | str | N | 结束月份（格式：YYYYMM） |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| month | str | Y | 统计月份，YYYYMM，如202601 |
| ann_date | str | Y | 公告/发布日期，YYYYMMDD |
| fc_res_usd | float | Y | 外汇储备，单位：亿美元 |
| fc_res_sdr | float | Y | 外汇储备，单位：亿SDR |
| usd_sdr | float | Y | 当月USD/SDR折算汇率，来源IMF |

## 接口示例

```python
# 导入sdk包
import tushare as ts


# 获取接口实例
pro = ts.pro_api()

# 获取2026年1月到2026年10月的外汇储备数据
df = pro.fx_reserves(start_date='202601', end_date='202610')
print(df)
```
